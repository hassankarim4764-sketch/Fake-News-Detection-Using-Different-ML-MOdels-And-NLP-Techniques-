# Fake News Detection Using Machine Learning & NLP

## Overview

This project detects whether a news article is fake or real using Machine Learning and Natural Language Processing (NLP) techniques.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* NLTK
* Matplotlib
* Seaborn

## Machine Learning Models

* Logistic Regression
* Random Forest Classifier
* MLP Classifier

## NLP Techniques

* Text Cleaning
* Stopword Removal
* Tokenization
* TF-IDF Vectorization
* N-Gram Analysis

## Results

Random Forest with 1-Gram TF-IDF achieved the highest accuracy.
